# 📚 Library Management System

## 📖 Project Description

The **Library Management System** is a comprehensive web application designed to digitize and streamline the daily operations of a modern library. The system facilitates the management of book inventories, user memberships, borrowing transactions, and reservations.

By transitioning from manual processes to a digital platform, this project aims to:

  * **Enhance User Experience:** Provide users with a dashboard to search for books, check availability, and manage their loans.
  * **Optimize Administration:** Empower librarians with tools to track overdue books, manage stock, and view transaction histories.
  * **Ensure Security:** Implement secure authentication and role-based access control (RBAC) for admins and standard users.

## 📅 Sprint Summary

The project development follows an Agile/Scrum methodology divided into 6 strategic sprints:

| Sprint | Phase | Key Deliverables |
| :--- | :--- | :--- |
| **Sprint 0** | **Project Analysis & Setup** | Requirements analysis, ERD design, Repo initialization, Tech stack definition. |
| **Sprint 1** | **Authentication** | User Register/Login, JWT Authentication, Role-based (Admin/User) authorization. |
| **Sprint 2** | **Book Discovery** | Book listing UI, Filtering & Search (Author/Category), Book Detail pages. |
| **Sprint 3** | **Borrowing & Reservation** | Borrowing logic, Stock management, Reservation system, Due date calculation. |
| **Sprint 4** | **User Dashboard** | Profile management, Active loans view, Transaction history, Favorites list. |
| **Sprint 5** | **Testing & Deployment** | Unit & Integration testing, Bug fixes, Production deployment. |

## 🛠️ Used Technologies

The project utilizes a modern and robust technology stack:

### **Frontend**

  *  **Next.js** - React framework for the user interface.
  *  **Tailwind CSS** - For responsive styling.

### **Backend & Database**

  *  **Node.js / Express** (or Java/Spring Boot) - Server-side logic.
  *  **PostgreSQL** - Relational database for data persistence.

### **Tools & DevOps**

  *  **Jira** - Project management and issue tracking.
  *  **Git & GitHub** - Version control.
